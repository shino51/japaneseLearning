# 息子くん用 ポケモンずかん

A4縦・1ページ4匹（2×2）のPowerPoint図鑑です。

## 画像について

画像は PokeAPI/sprites の `official-artwork` PNG を、ポケモンの全国図鑑番号から自動取得します。
そのため、画像ファイルを手作業で探す必要はありません。

PokeAPI/sprites:
https://github.com/PokeAPI/sprites

## Windowsでの使い方

PowerShellでこのフォルダに移動して、

    py -m pip install -r requirements.txt
    py generate.py

を実行します。

初回は8匹分の画像を `images/` に自動ダウンロードし、その後 `pokemon_zukan.pptx` を作ります。

## 新しいポケモンを追加するとき

`data/pokemon.csv` に1行追加します。

`id` は全国図鑑番号です。
`hiragana` は子ども向けに読ませたい表記なので、必要なら自由に調整できます。

画像のファイル名は例えば `999.png` のような全国図鑑番号に固定しても構いません。
現在は分かりやすい英語名のファイル名にしています。

## デザイン変更

PowerPointの見た目は `generate.py` の `add_pokemon_slide()` を変更します。
CSVのデータはそのままなので、デザインを何度でも作り直せます。

# ポケモン ひらがなカード

CSVに記録した「出会った日」を使って、指定した日付範囲のポケモンの名前に必要な
ひらがなカードを自動生成します。

## 日付範囲

開始日・終了日は両方とも含みます。

例：

    py generate_hiragana_cards.py --start 2026-08-01 --end 2026-08-16

土日をまたぐ範囲もOKです。

## CSV

`data/pokemon.csv` の `encountered_date` に、

    2026-08-10

のように日付を入れてください。

例えば：

    004,ヒトカゲ,ひとかげ,Glumanda,ほのお,,glumanda.png,2026-08-10

## カードの考え方

指定範囲に含まれる全ポケモンの名前を完成させるために必要な文字を、
必要な枚数だけ作ります。

例えば「ひとかげ」なら、

    ひ / と / か / げ

が1枚ずつ入ります。

同じ文字が複数回必要な名前（例：ぽっぽ）なら、
その文字も必要な枚数だけ入ります。

さらに既定で20枚のダミー文字を追加します。
`--distractors 30` のように変更できます。

## 今後追加できそうな機能

- ポケモンの絵＋名前の「お題カード」も自動生成
- カードをもっと大きくする
- 裁断しやすい余白・点線
- 同じ文字のカードを複数セット作る
- 難易度（横向き/縦向き/小さい「っ」など）を調整
